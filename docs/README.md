# Docs Index

These files are the persistent project context for future Codex sessions and
human maintainers.

- `PROJECT_STATE.md` - current project state, architecture, invariants, and limits.
- `DECISIONS.md` - durable architectural and product decisions with rationale.
- `TASK_LOG.md` - chronological log of meaningful work and validation.
- `NEXT_STEPS.md` - current actionable tasks, open questions, risks, and backlog.

For any meaningful change to architecture, data model, storage, authorization,
business logic, API, integrations, migrations, deployment, or testing, update
the relevant files in this directory.
